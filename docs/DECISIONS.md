# Decisions

One row per decision that would otherwise be re-argued: what holds, why, and
what else was considered. Every row describes the present. To change one,
replace it in the same change that changes the code, and say in the commit
what it replaced; this file does not keep the old row.

The complement is [RESERVATIONS.md](./RESERVATIONS.md): what is *not* settled.

## Product

| Decision                                                                                                                                                         | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Instead of                                                                                                                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| The WorkLedger is the source of truth; the FeatureManager is the only human surface                                                                              | Durable state must survive a crash; isolated directories are a consequence of the ledger, never the source. The operator must not open the ledger to know where a feature stands: the emitter's events are the whole human surface                                                                                                                                                                                                                                                                                  | Isolated directories or the tracker as truth; a ledger UI; humans driving each Gate                                                               |
| One active FeatureStandard per Project; Subtasks run one at a time                                                                                               | Isolation and integration stay simple; the dependency graph chooses order, it does not authorise parallelism                                                                                                                                                                                                                                                                                                                                                                                                        | Parallel Subtasks; concurrent features on one Project                                                                                             |
| Nothing enters WorkLineStable until every Subtask passed its Gates **and** the assembled feature was judged                                                      | The two sequences are separate: a check right for one unit can be wrong for the whole                                                                                                                                                                                                                                                                                                                                                                                                                               | Folding each Subtask straight into WorkLineStable; one Gate sequence for both                                                                     |
| The human is an escape hatch, not the engine                                                                                                                     | The happy path completes with no approval; an escalation freezes the feature and carries a Trace                                                                                                                                                                                                                                                                                                                                                                                                                    | Human validation of every Subtask; silent retries with no Trace                                                                                   |
| The plan is frozen once FeatureBreakdown accepts it                                                                                                              | An in-flight re-breakdown makes Attempts and directories unverifiable. A wrong plan is abandon and recreate                                                                                                                                                                                                                                                                                                                                                                                                         | Automatic re-plan when a later Subtask fails                                                                                                      |
| Work reaches the integration work line through a Submission judged by an outside Authority; WorkLineStable is the system's copy of the line that Authority holds | A local fold makes the work invisible: no branch, nothing an outside check can run against. The Authority runs the checks the team trusts; its refusal carries a report and feeds the next Attempt like a Gate's, so there is one failure path. Once it folds, the copy is stale and the next Isolation starts from the new state. With no Authority, WorkLineStable is the reference and the fold is local                                                                                                         | A second error path for outside refusals; a human approving each Submission; treating the copy as the reference and letting the Authority diverge |
| The system stops at the integration work line                                                                                                                    | Release, deploy, and folding that line onto a reference such as `main` are somebody else's                                                                                                                                                                                                                                                                                                                                                                                                                          | A `publish` key that opens pull requests; Host flags named after one tracker                                                                      |
| The names: Implementer runs one Subtask, Conductor sequences a feature, WorkLedger stores                                                                        | *Orchestrator* claimed coordination the Subtask runner does not do; *FeatureConductor* carried a tracker noun onto a sequencer that could deliver a book; *TaskBoard* read as a visual kanban                                                                                                                                                                                                                                                                                                                       | Orchestrator, Runner, Executor; FeatureConductor, Glue; TaskBoard, FeatureLedger                                                                  |
| The operator live view (`mason watch` / `status`) is read-only                                                                                                   | The team acts only in the FeatureManager. The operator needs to see the machine without restarting the worker or opening the ledger by hand; watch snapshots the ledger and follows a journal, and cannot claim, cancel, or `ready`                                                                                                                                                                                                                                                                                 | Watch merged into `run` as a TUI (closing the screen would stop the loop); densifying `progress` on the tracker; parsing the persistence files    |
| On a GitHub poll, a `ready` label on an `escalated` feature is `ready`                                                                                           | A listing is a snapshot with no `labeled` edge; without this a human who adds the label after an escalation is ignored                                                                                                                                                                                                                                                                                                                                                                                              | Requiring webhooks for resume; storing previous labels in the Cursor                                                                              |
| A FeatureStandard carries an intention and no list of acceptance criteria; the only definition of done is a Subtask's, written by the Planner                    | Replaces: an upsert needed at least one criterion, read from the issue's task list or an `Acceptance criteria` heading. The list said again, in bullets, what the intention already said, and nothing ever checked one against the other: FeatureBreakdown declined the coverage check as semantic, and at the assembly stage the criteria were joined into a definition of done nobody had written for the whole. What the work must meet is now said once, in the intention, and per unit in `definition_of_done` | A required list nothing verifies; a coverage check making FeatureBreakdown a second Planner; keeping the field optional and unread                |

## Kernel

| Decision                                                                                                                                                                                                       | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Instead of                                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| A kernel package imports nothing outside itself; Conductor may import WorkLedger                                                                                                                               | The same packages could deliver a book: they speak intention, plan, attempt, directory — not GitHub, git, or a file format. `scripts/check-kernel.mjs` refuses the rest                                                                                                                                                                                                                                                                                         | A shared runtime library; a package under `plugins/` imported by a Transformer                                                   |
| A Transformer is one IN, one job, one OUT                                                                                                                                                                      | A toolbox of operations is not a Transformer; the caller copies one OUT into the next IN                                                                                                                                                                                                                                                                                                                                                                        | One WorkSpace toolbox with many verbs; Conductor as a Transformer                                                                |
| Isolation is two Transformers: Isolator (Parent → Child) and Integrator (Child + Parent → `integrated` \| `conflict`, never forced)                                                                            | Implementer needs a directory it did not create; something must fold it back without forcing a merge                                                                                                                                                                                                                                                                                                                                                            | One WorkSpace toolbox; git commands in the caller                                                                                |
| A Transformer is a function; its CLI is a thin adapter                                                                                                                                                         | The composition root is TypeScript and must import or spawn a Transformer from one build                                                                                                                                                                                                                                                                                                                                                                        | CLI only; a library with no binary; two entry implementations                                                                    |
| Builder and Gate are command slots, not Transformers                                                                                                                                                           | Implementer treats them as opaque children; the kernel runs without a chosen producer                                                                                                                                                                                                                                                                                                                                                                           | A Builder Transformer and a Gate Transformer                                                                                     |
| Conductor talks to Transformers through an injected Transformer Port (`TransformerPort`); the name says what is behind it, like Manager Port, Persist Port and Authority Port                                  | The loop must be testable without a `dist/` and must not freeze the isolation method; the caller wires the four. Renamed from Brick Port on 2026-09-16: "Brick" was a word from the Block era with no glossary row and no meaning of its own                                                                                                                                                                                                                    | Conductor depending on the four packages; spawning CLIs from argv inside the loop; keeping Brick as a term in its own right      |
| Isolator and Integrator receive a strategy; they do not sniff `.git`                                                                                                                                           | How a Child is attached and folded is one Project decision, made once. The CLIs require `--strategy`                                                                                                                                                                                                                                                                                                                                                            | Sniffing inside the Transformers; two config keys that can disagree; Conductor choosing                                          |
| Every child of a Task carries its own ceiling; there is no Attempt clock and no Task clock                                                                                                                     | A budget derived from a deadline once left the Gates a millisecond to judge in: the run lost the judgement, not just the build. What bounds a Task is `maxAttempts × (producer + Σ gates)`, arithmetic anyone can check                                                                                                                                                                                                                                         | Both clocks with each child capped under them; a hard-coded ceiling for a Gate that names none                                   |
| The WorkLedger owns the Persistence Port; a backend owns the bytes                                                                                                                                             | SQLite or Postgres must not edit transition code. `src/ledger/` imports no adapter and no `node:fs`; a test asserts it                                                                                                                                                                                                                                                                                                                                          | `if (sqlite)` in the ledger; backend sniffing from an environment variable                                                       |
| `EscalationKind` names where the whole stopped — `plan`, `subtask`, `assembly`, `submitted`, `merging` — and a refusal's report and its refuser's name stay on the record until a producing pass consumes them | An escalation reported as a Subtask that did not fail sent the reader to the wrong place; a Submission re-offered without its last report, or a repair told "the producer did not finish" when `ci-green` refused, gave the next Attempt and the human nothing to act on. `markSubmitted` carries `last_report` and `last_refused_by`, `escalate` takes the report that caused it, `ImplementInput.reportFrom` names the refuser all the way to `--report-from` | One `subtask` kind for everything; rebuilding the Submission record field by field on republish; a report handed on unattributed |
| A repair produces **before** the Integration that takes its work up                                                                                                                                            | Fold, then produce, then publish left the repair loose in the workspace until the *next* round's fold: the Submission carried the state from before the repair and was refused again for the same reason, word for word, and the whole refusal budget went on the delay. `align` is the one Integration that commits what a producer leaves in the feature workspace, so the producer runs first                                                                | Fold before produce; a second fold between produce and publish                                                                   |

## Host

| Decision                                                                                                                                                                                                                                                               | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Instead of                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Host is `packages/host/runtime`: the composition root and the binary `mason`                                                                                                                                                                                           | Someone owns the Cursor, loads the plugins, calls Conductor, reports. That is many operations, not a Transformer                                                                                                                                                                                                                                                                                                                                                                                                          | A Conductor CLI that imports Transformers; the process as a walkthrough script                                                                                                                                            |
| `runtime` is four layers, one import direction: `config → plugins → loop → operator`                                                                                                                                                                                   | Host is where everything meets, so it is the package most likely to tangle. `scripts/check-host.mjs` refuses a backwards import, a fifth directory, and a file above the layers other than `index.ts` and `cli.ts`                                                                                                                                                                                                                                                                                                        | One flat `src/`; splitting `operator/` into its own package first                                                                                                                                                         |
| Host's code names no plugin: it loads a manager, an isolation strategy, a persistence backend by the name a config gives                                                                                                                                               | The pipeline must stay valid for any job, including one with no git remote. One loader (`plugins/load.ts`), one `Shape` per kind; the names Host ships with are strings in `config/defaults.ts` and nowhere else; the check refuses a plugin import or a spelled-out name anywhere else                                                                                                                                                                                                                                   | Hard-wiring fake and GitHub; `if (manager === github)`; a `persist` switch over an imported default                                                                                                                       |
| Host's `package.json` declares exactly the plugins a config written by `mason init` needs, and no manager                                                                                                                                                              | A default that is not installed is a broken `init`. Host cannot choose a tracker                                                                                                                                                                                                                                                                                                                                                                                                                                          | Every plugin as a dependency; none, with an install step after `init`                                                                                                                                                     |
| A FeatureManager is one `manager-*` package implementing `@bluewombat/manager-kit`; its listen / adapt / report are modules inside it                                                                                                                                  | Host consumes one `ManagerPort`. Three published pieces plus an assembler made six packages for two trackers                                                                                                                                                                                                                                                                                                                                                                                                              | Three Transformers per tracker; one package with three verbs                                                                                                                                                              |
| The reference work line is named by the manager and read by the isolation strategy; Host copies the words through unread                                                                                                                                               | With an Authority the reference lives where the Authority is; the local directory is Host's copy. `referenceManager` returns an opaque record, `strategy.reference.parse` reads it strictly and hands back the target, an offline `inspect`, and a `materialize`                                                                                                                                                                                                                                                          | `{ remote, branch }` typed in the kit (a git contract in the kernel); Host cloning from a key it reads itself; checking the copy lazily at the first Isolation                                                            |
| The isolation strategy names its Child (`refOf`); the Authority relays that name to the Publisher                                                                                                                                                                      | Host must not assume a branch. A strategy without `refOf` names the Child by its id                                                                                                                                                                                                                                                                                                                                                                                                                                       | Host importing `isolation-git` for a branch name                                                                                                                                                                          |
| The system acts under its own identity: the token's account on the tracker, `commitAuthor` on its commits, the token on git transport. Only the issue is a person's                                                                                                    | Commits signed by the operator's machine and pushes over the operator's SSH key made a person the author of work an agent did. The manager names `credentialEnv` and `author` on the reference; `isolation-git` turns them into the git environment of the run — a credential helper that reads the token when git asks, after clearing the machine's own helpers, and nothing on disk. Host hands that environment to the Publisher and the Refresher only, never to its own process: a Builder must not inherit a token | SSH by default (the machine's key, the machine's account); an invented `Integrator <integrator@…>` author; the token in `.git/config` or in a URL; `process.env` set at boot (every Builder would inherit the credential) |
| Host may read a JSON config; Transformers do not                                                                                                                                                                                                                       | `mason run` has a dozen paths and slots; a file next to the clone is the operator surface, flags override it. Transformers stay one-shot argv                                                                                                                                                                                                                                                                                                                                                                             | Env-only config; per-Transformer config files                                                                                                                                                                             |
| The Project config is one block per moment — `planner`, `builder`, `assembly`, `authority` — and every command names its own `cmd` and `timeoutMs`                                                                                                                     | A fallback such as `?? builder.cmd` meant an agent could run that nobody had written down, the one thing a config for unattended work must not allow                                                                                                                                                                                                                                                                                                                                                                      | Nested `builder.assembly`; a flat `assemblyRepair`; inheriting `timeoutMs` from a neighbour                                                                                                                               |
| Assembly has no producer: it is judged, and a refusal is `fix`                                                                                                                                                                                                         | The assembled feature is made of validated units; the first pass is Gates only, a refusal is a surgical correction of what the judgement named                                                                                                                                                                                                                                                                                                                                                                            | `assembly.producer` for symmetry; a first producing pass with no report                                                                                                                                                   |
| A Project may name a different producer for a first pass and for a repair; the repair producer is chosen on the presence of a report                                                                                                                                   | Making from a specification and resolving a refusal are different jobs. A Task an Authority sent back carries a report from its first Attempt, so the Attempt number is the wrong discriminator                                                                                                                                                                                                                                                                                                                           | One producer with the prompt as the only variable; choosing on the Attempt number                                                                                                                                         |
| The GitHub listener polls the issues listing                                                                                                                                                                                                                           | A webhook needs a public endpoint, a secret, and a queue; a token and a poll need none, and a subscription resumable from a Cursor is testable from a laptop                                                                                                                                                                                                                                                                                                                                                              | A webhook receiver; GitHub's events API                                                                                                                                                                                   |
| A manager's transport is a maintained dependency — `@octokit/core` with retry and throttling — and the token is an injected channel, never in the invocation                                                                                                           | Retrying `5xx` and pacing writes are solved problems; a hand-written client was 262 lines nobody else reviews. The run function is testable with no network and no credential; the CLI reads the named environment variable                                                                                                                                                                                                                                                                                               | A hand-written client; `@octokit/rest`; `gh`; the token as an argument                                                                                                                                                    |
| No retry outlives the invocation's duration clock                                                                                                                                                                                                                      | A rate-limit reset an hour away must not turn a one-minute invocation into an hour. The plugins decide how to wait; the manager decides whether there is time left                                                                                                                                                                                                                                                                                                                                                        | Letting the plugin wait as long as GitHub asks; a fixed retry ceiling                                                                                                                                                     |
| A slot flag whose value this system *writes* (`--transcript-dir`) resolves against the config directory; any other path-looking token resolves only if it already exists                                                                                               | An output path has not been written yet, so "resolve if it exists" left it relative to the slot's working directory — the Task workspace — where transcripts died with the workspace, were committed into the pull request, and satisfied `workspace-changed` on their own                                                                                                                                                                                                                                                | Resolving every token (a word that looks like a path becomes one); requiring an absolute path in the config                                                                                                               |
| After a listen that reached the source, Host asks optional `probe` of every Feature abandon is still legal for; `gone` is a cancel. `mason cancel <key>` is the same cancel when the manager cannot answer                                                             | A poll cannot see an absence: a deleted item never appears again. Treating "not on this page" as gone would cancel every frozen escalation the `since=` window misses. Host talking to GitHub would break the Port                                                                                                                                                                                                                                                                                                        | Webhooks only; Host `GET /issues`; inferring gone from an empty poll page; treating every fetch failure as gone                                                                                                           |
| `done` names the Authority's reference and the fold's commit when there was an Authority, and nothing otherwise                                                                                                                                                        | A local fold has nothing a reader of the tracker could open, and the path Host used to publish in its place was the operator's username and directory layout, on an issue that may be public                                                                                                                                                                                                                                                                                                                              | The work line's absolute path; its basename                                                                                                                                                                               |
| A Feature the tracker no longer lists is abandoned by the sweep, and `mason cancel <key>` abandons one by hand                                                                                                                                                         | A poll cannot see an absence: a deleted issue never appears again, and an `escalated` record — active by design — froze its Project for good. After each listen that reached the source, Host asks the manager's `probe` about every Feature abandon is still legal for; `gone` is the same abandon as a `cancel` delivery, `unavailable` is not. The CLI is the hatch for a tracker that cannot say it                                                                                                                   | Editing the ledger by hand; treating "absent from the poll" as deleted (it also means "not updated")                                                                                                                      |
| Every Event that states a fact carries an `eventId` naming that fact; the manager says nothing it already has. An escalation is `<key>:escalated:<round>:<kind>[:<subtask>]`, a resume `<key>:resumed:<round>`, where the round is the ledger's count of `ready` taken | The in-process `said` set covers one process; only an id the manager can recognise covers a restart. The Attempt count cannot name a round — a Plan refused, resumed and refused again has none — and an id that collides drops an escalation, which is worse than saying one twice. `escalation_reminder` alone stays unnamed: repetition is its point                                                                                                                                                                   | Ids on two Events only; `attempts_used` as the round; a timestamp (not reproducible after a crash)                                                                                                                        |
| An Attempt is stamped with its round (`resumes` when recorded), and a Subtask escalation counts this round's Attempts alone against the budget                                                                                                                         | The budget is per round — a resume starts the Subtask from zero — while the ledger keeps every Attempt as history. Counting the record against the budget read "refused it 6 times of 3", a sentence a person cannot act on; the round is the one field that tells the two apart, and the report says which round it was when it is not the first                                                                                                                                                                         | Dropping the earlier Attempts on resume (the history is what a reader of the ledger wants); taking the last `maxAttempts` (wrong the day a round is shorter, e.g. fail-blocking on the first)                             |

## Plugins and kits

| Decision                                                                                                                                                                                              | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | Instead of                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A plugin imports its kit and the kernel Ports it implements — never `runtime`, never another plugin                                                                                                   | A plugin answers a contract and knows nothing of who calls it; a third-party plugin is the same thing in another repository. `scripts/check-plugins.mjs` refuses the rest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Plugins depending on Host for shared helpers                                                                                                                                               |
| The contracts a plugin answers are kits under `packages/host/`: `manager-kit`, `slot-kit`. A contract without plumbing to share is a `Shape` in `runtime/src/plugins/`                                | A kit is what a plugin author imports; it depends on nothing in the repository. Isolation and persistence need a type and a check, not a kit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | A kit per contract regardless; the kits inside `runtime`                                                                                                                                   |
| The shipped slots are one package, `slots`; a slot is any command that prints the right JSON line                                                                                                     | Spawned, never imported: nothing about a slot belongs to the package that spawns it. One package per slot is not justified by eight files                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Slots inside Host; a TypeScript interface a slot implements (ending language independence)                                                                                                 |
| A vendor agent and a prompt role are two commands, composed with `--`                                                                                                                                 | Filling placeholders and talking to Cursor or Claude are two jobs; a role owns a closed set of names and writes the filled prompt to a file, an agent takes the text and does not interpolate                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | One Builder that interpolates; a `--agent` flag on the role; importing the agent as a library                                                                                              |
| A vendor agent CLI's one-line JSON (`SerializedRun`) always carries `skills` and `usage`; `null` means unknown, `[]` / zero means looked and found none. Each wrapper parses its own vendor stream    | Roles and Host must not guess Cursor vs Claude event shapes. A Codex (or any future) agent that cannot extract leaves `null` and stays valid. Distinguishing "none" from "unknown" is the point of the default                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Omitting the fields; defaulting `skills` to `[]` (ambiguous); putting vendor parsers in `slot-kit`                                                                                         |
| A feature's Submission is described in the human's words by default; a Describer (`authority.describe`), once per feature, may say them differently. Subtask folds are never customised               | A squash whose message was the pull request's markdown — headings, ticked boxes nobody had checked, the plan as "steps" — was a commit no team would write; and a convention is the team's, so Host cannot pick one. The default assumes nothing: the issue's title, its body as written, `Closes #N`. A team with a convention names a Describer — a script for a rule, an agent under `--rules-file` for a judgement — and pays for it once per feature, since that message is what people read. Host passes the description on as `{ subject, body }` and the manager decides what it becomes: the words "commit" and "pull request" live in the git components only, since a Project may run without git. Subtasks are folded again into the feature: their folds get the intention's headline (the Planner is asked to write one, commit-shaped), else its first sentence, whole words, no markdown, and no slot | Conductor composing commit messages (a kernel that would know one team's style); the manager guessing a convention; asking an agent per Subtask; the squash carrying the pull request body |
| The ledger backend is a plugin (`persist`), default `persist-fs`, and `watch` opens it the same way `run` does                                                                                        | Two backends through one face is what proves the seam; a `watch` reading a fixed backend would show an empty board the day a Project chose SQLite                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | `persist` required like `workLine.isolation`; the adapters inside the ledger package                                                                                                       |
| Every Gate is told `--stage`; `workspace-changed` passes on an assembly                                                                                                                               | The rule it enforces is about a unit of work. An assembly is made of work already validated on its own, so a repair that finds nothing left to do is right to change nothing; refusing it made the next Attempt invent an edit to be seen to have edited. A Gate that cannot tell the two stages apart must not be the one to decide                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | A `produce: false` guard on the judgement pass only; a separate Gate list for assembly                                                                                                     |
| `ci-green` accepts a commit with no check unless `--require-checks`; with the flag it waits until the Gate's timeout                                                                                  | A minute of grace counted from the commit was a guess, and it slipped on the republish path: a commit whose checks registered after the fold went in unjudged. Whether a work line has checks is a fact the Project states, not one the Gate infers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | A grace period; reading the required-checks list from the repository's protection rules                                                                                                    |
| The Submission body carries the tracker's closing keyword (`Closes #<n>`), so the issue closes when the Authority folds                                                                               | An issue left open under `mason:done` read as unfinished on a board, and the pull request named its issue only in prose. The fold *is* the end of what mason does; linking the two pages is the tracker's own feature                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Leaving the issue open because mason stops at the integration work line; closing it from Host with an API call                                                                             |
| GitHub `probe` maps 200 open → `present`, 200 closed or 404/410 → `gone`, anything else → `unavailable`                                                                                               | Closed is already cancel via the adapter; deleted is 404. A 404 is also "no access", so Host only probes after a listen that listed the repository                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Mapping every fetch error to gone; a webhook `deleted` action the poll never sees                                                                                                          |
| `ci-green` has no default for `--token-env`; the argv must name the variable                                                                                                                          | The old default was `GITHUB_TOKEN`, the one name `gh` reads ahead of its own login, so the operator must not export it — and a Gate that fell back to it refused only at the first assembly of a real run, two config keys apart from the manager's `tokenEnv` that had been set correctly                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Defaulting to the manager's name (the Gate knows no manager); keeping `GITHUB_TOKEN`                                                                                                       |
| `mason setup` checks that the branch pull requests are opened onto exists, and names the repository's default branch when it does not                                                                 | `branch` defaults to `main` so `doctor` stays offline; a repository on `master` used to fail at the first run, one step after `setup` had already been on the network. `setup` cannot write the config — it says what to write                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | Reading the default branch at every run; `setup` editing `mason.config.json`                                                                                                               |
| The git Refresher's refusal on a diverged copy says the way out — `git -C <copy> reset --hard origin/<branch>`, or delete it — not git's words alone                                                  | The copy is the system's and is refetched at every start, so nothing in it is worth keeping; the person reading `mason run`'s trace needs the one command, and Host stays tool-neutral by leaving the git sentence to the git slot                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Host printing a git command; leaving git's stderr as the whole reason                                                                                                                      |
| The issue body is the intention verbatim, less the tracker's own furniture — template comments and task-list boxes — so that ticking a box is not an edit                                             | The fingerprint hashes the intention and is what tells an edit from an echo; a body taken byte for byte made a ticked checkbox, the most ordinary gesture on a GitHub issue, into a pending fingerprint and a frozen Feature. The stripper reads nothing — no criteria, no headings — it removes a syntax, and leaves the bullet and the words                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | The body byte for byte; the old body parser (criteria out, and a notion of "done" mason does not have); normalising `[x]` to `[ ]` and keeping the boxes                                   |
| A producing template must place `{{rules}}`; a role refuses one that does not, before any agent runs                                                                                                  | The bounds — one directory, nothing committed, nothing pushed — are what lets the Gates see the work; a template that left them out learnt it from a refused Attempt, one run later and on the tracker. The Project keeps the right to write its own rules (`--rules-file`), not to say none                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Prepending the bounds no matter what (a template the Project cannot shape); leaving the omission legal (C14, the slower failure)                                                           |
| A Child is the Parent's working files less a list the Project names (`workLine.isolationOptions.exclude`), `.env` and `.env.*` by default; the strategy reads the list, Host copies it through unread | A secret in the clear was duplicated into every workspace an agent reads and a pull request may carry, and nothing said so.
